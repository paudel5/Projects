# Simple Clock

A basic digital clock made with HTML, CSS, and JavaScript.

## What it does
- Shows the current time and updates every second
- Shows today's date
- Button to switch between 12-hour and 24-hour time
- Button to toggle dark/light mode

## How it works
- `setInterval()` runs the `updateClock()` function once every second
- JavaScript's built-in `Date` object is used to get the current time
- Button clicks are handled with `addEventListener`

## How to run it
Just open `index.html` in a browser. No installation needed.
